### الهيئة العامة للزكاة -- الجمهورية اليمنية

## 📌 1. نظرة عامة ورؤية المشروع

منظومة **«رشاد AI»** هي منصة مؤسسية ذكية صُممت خصيصاً لمساندة الهيئة العامة للزكاة في أتمتة وتدقيق دورة معالجة طلبات المساعدات الزكوية، وتحليل مؤشرات الاحتياج بدقة علمية قابلة للتفسير، وحل مشكلات الازدواجية والتكرار، واستخراج بيانات الوثائق الرسمية بالرؤية الحاسوبية، مع حماية تامة لخصوصية المستفيدين وسيادة البيانات.

### ⚖️ المبدأ الحاكم والحوكمة الشرعية (Human-in-the-Loop)
* المنظومة **أداة دعم قرار وتحليل إحصائي مساند فقط**، وليست جهة تصدر أحكاماً شرعية أو قانونية.
* لا يتخذ النظام أي قرار نهائي بالقبول أو الرفض أو الاستبعاد الآلي.
* يظل القرار النهائي دائماً بيد اللجان الشرعية والباحثين الميدانيين والمختصين وفق اللوائح المعتمدة بالهيئة.
* جميع البيانات المستخدمة في التطوير والاختبار هي **بيانات اصطناعية مولدة برمجياً (Synthetic Data - Seed: 42)**؛ ولا يُستخدم أي بيان حقيقي لأي مستفيد حقيقي في هذه النسخة.

## 🛠️ 2. البنية التقنية وما تم استخدامه في المنظومة (Tech Stack)

### أ. الواجهة الخلفية والخوادم (Backend)
- **لغة البرمجة:** `Python 3.14.7`
- **إطار العمل الأساسي:** `FastAPI 0.162.0` (واجهات برمجة تطبيقات RESTful فائقة السرعة وغير متزامنة).
- **المخططات والتحقق:** `Pydantic v2.14` مع `ConfigDict` لضبط حقول الإدخال والإخراج.
- **طبقة الوصول للبيانات (ORM):** `SQLAlchemy 2.1.8` بنظام النماذج الحديثة `Mapped[...]` و `mapped_column`.
- **مشغل قاعدة البيانات:** `psycopg 3.3.8` (أحدث مشغلات PostgreSQL عالية الأداء).
- **الأمان والتحقق من الهوية:** `PyJWT 2.15` لتوليد رموز التوثيق الموقعة، و `bcrypt 5.0` لتشفير كلمات المرور بدون مستودعات وسيطة غير مستقرة.
- **بيئة الاختبار وضمان الجودة:** `Pytest 9.2` مع تغطية آلية شاملة (22 اختبار ناجح بنسبة 100%).

### ب. نماذج الذكاء الاصطناعي وتعلم الآلة (AI & Machine Learning Suite)
- **المكتبات:** `Scikit-Learn 1.9.1`, `Pandas 3.1.1`, `NumPy 2.5.4`, `SciPy 1.18.1`, `Joblib 1.6.0`.
- **نماذج تعلم الآلة المدربة والمحفوظة داخل `ai/models/`:**
  1. **نموذج عنقدة الأسر واكتشاف الهشاشة (`K-Means Clustering`):**
     - تجميع الأسر في 4 عناقيد احتياج واقعية (Archetypes) دون تحيز مسبق:
       * *عنقود 0:* أسر نازحة ومعدمة شديدة الهشاشة (فاقدو المأوى، انعدام دخل).
       * *عنقود 1:* أسر ذات أعباء صحية وإعاقات مزمنة (كفالة علاجية + إعانة معاقين).
       * *عنقود 2:* أسر كبيرة بمعدل إعالة ودخل شحيح (مساعدة نقدية موسعة).
       * *عنقود 3:* أسر محدودة الدخل مع استقرار نسبي (مشاريع تمكين اقتصادي).
  2. **نموذج تصنيف أولوية الاحتياج (`Random Forest Classifier`):**
     - 100 شجرة قرار، دقة اختبار **74.4%**، مع حساب أهمية كل متغير (Gini Feature Importance).
  3. **نموذج التنبؤ بالطلب والمساعدات (`Random Forest Regressor`):**
     - التنبؤ بحجم المنحة النقدية الطارئة بالريال اليمني (YER) لكل أسرة ($R^2 = 0.888$).
  4. **محرك الأساس الإرشادي الشفاف (`Multi-Criteria Rule-Based Baseline`):**
     - نظام أوزان معلن وغير مبهم: دخل 30%، إعالة 25%، صحة 25%، سكن 20%.
  5. **محرك كشف الازدواجية المشبوهة (`Duplicate Detection Engine`):**
     - مطابقة تامة بالرقم الوطني والهاتف + مطابقة احتمالية بالرموز الثلاثية للأسماء العربية (`pg_trgm`) مقترنة بالجوار الجغرافي.
  6. **خط معالجة الوثائق والرؤية الحاسوبية (`Document Intelligence & OCR`):**
     - معالجة رقمية للصور (Pillow Filters: تباين، عتبة ثنائية، إزالة تشويش)، واستخراج الحقول مع حساب نسبة الثقة لكل حقل، وتوليد بطاقات هوية تجريبية للتحقق البشري جنباً إلى جنب.

### ج. قاعدة البيانات والتنظيم المكاني (Database & Geography)
- **المحرك:** `PostgreSQL 18.6` (محلي).
- **الإضافات:** تفعيل امتداد `pg_trgm` للمطابقة النصية العربية السريعة.
- **الهيكل الإداري:** تم تحميل التقسيم الإداري الرسمي للجمهورية اليمنية:
  - 5 محافظات (صنعاء، أمانة العاصمة، الحديدة، تعز، عدن).
  - 12 مديرية.
  - 13 عزلة.
  - 43 قرية وحارة.
- **البيانات الأولية:** 150 أسرة اصطناعية، 761 فرداً، 150 طلباً، و29 معرفاً مؤقتاً لحالات فاقدي الوثائق بإفادة عقال الحارات.

### د. الواجهة الأمامية وتجربة المستخدم (Frontend)
- **إطار العمل:** `React 19` مع `TypeScript`.
- **أداة البناء والتطوير:** `Vite 8.3` مع محرك Rolldown.
- **التصميم والتنسيق:** `Tailwind CSS v4` مع دعم أصلي كامل للغة العربية والاتجاه من اليمين إلى اليسار (`dir="rtl"`).
- **الأيقونات:** `Lucide-React`.
- **الخصائص التفاعلية:**
  - شريط التبديل السريع بين الأدوار بنقرة زر واحدة (Quick Role Switcher).
  - لوحة إحصائيات ومؤشرات توزيع الأسر حسب المحافظات والمديريات.
  - بطاقة التفسير الذكي التفاعلية (مقارنة خط الأساس الإرشادي مع تنبؤات تعلم الآلة).
  - واجهة التحكيم البشري الثنائي لفض حالات الازدواجية المشبوهة.
  - شاشة المراجعة البصرية للوثائق المستخرجة جنباً إلى جنب.
  - التجهيل التلقائي لبيانات المستفيدين عند تسجيل دخول محلل البيانات (`pseudo_id`).

## 🚀 4. دليل التثبيت والتشغيل المحلي (Step-by-Step Guide)

### المتطلبات المسبقة:
- تثبيت `Python 3.12+` و `Node.js 20+` و `PostgreSQL 16+`.
- التأكد من تشغيل خدمة PostgreSQL محلياً، ووجود قاعدة بيانات باسم `rashad_ai_dev`.

---

### الخطوة الأولى: تشغيل الخادم الخلفي (Backend)

افتح نافذة **PowerShell** ونفّذ الأوامر التالية:

```powershell
# 1. الانتقال لمجلد الخادم الخلفي
cd C:\Users\pc\.gemini\antigravity\scratch\rashad-ai\backend

# 2. تفعيل البيئة الافتراضية
.\.venv\Scripts\Activate.ps1

# 3. تشغيل خادم FastAPI
uvicorn app.main:app --reload --port 8000
```

✅ **الروابط المتاحة بعد التشغيل:**
- واجهة فحص الصحة: `http://localhost:8000/health`
- التوثيق التفاعلي للـ API (Swagger UI): `http://localhost:8000/docs`

---

### الخطوة الثانية: تشغيل الواجهة الأمامية (Frontend)

افتح نافذة **PowerShell ثانية** ونفّذ الأوامر التالية:

```powershell
# 1. الانتقال لمجلد الواجهة الأمامية
cd C:\Users\pc\.gemini\antigravity\scratch\rashad-ai\frontend

# 2. تشغيل خادم التطوير السريع
npm run dev
```

✅ **الرابط المتاح بعد التشغيل:**
- لوحة تحكم رشاد AI: `http://localhost:5173`

---

### الخطوة الثالثة: تشغيل الاختبارات الآلية (Pytest)

للتحقق من سلامة جميع المكونات البرمجية ونماذج الذكاء الاصطناعي:

```powershell
.\.venv\Scripts\python.exe -m pytest tests -v
```
*(النتيجة المتوقعة: نجاح 22 اختباراً بنسبة 100%)*

إذا أردت إعادة تدريب نماذج تعلم الآلة (K-Means, Random Forest, Demand Regressor) وتحديث تقرير الأوزان:

## 🧪 5. سيناريوهات التجربة الموصى بها في الواجهة

1. **تجربة التفسير الذكي ومقارنة تعلم الآلة:**
   - ادخل بحساب مسؤول البرامج (`programs_officer`).
   - اختر أي أسرة من القائمة واضغط على زر **«عرض التفسير الذكي للاحتياج»**.
   - تنقل بين تبويب **«تنبؤات وعناقيد تعلم الآلة»** لرؤية العنقود المكتشف وقيمة المنحة المقدرة، وتبويب **«خط الأساس الإرشادي»** لرؤية توزيع النقاط.
2. **تجربة معالجة وثائق الهوية بالـ OCR:**
   - ادخل بحساب أخصائي التسجيل (`beneficiary_officer`).
   - اضغط على زر **«معالجة وثيقة هوية جديدة (OCR)»**.
   - اضغط على **«توليد بطاقة هوية تجريبية ومعالجتها»**.
   - راجع النص المستخرج جنباً إلى جنب مع صورة البطاقة، وعدّل أي حقل ثم احفظ الاعتماد البشري.
3. **تجربة فض الازدواجية المشبوهة:**
   - انقر على تبويب **«كشف الازدواجية المشبوهة»**.
   - استعرض السجلات المشتبه بتكرارها (بسبب تطابق الهاتف أو تقارب الأسماء العربية).
   - اتخذ إجراء التحكيم البشري (تأكيد الدمج أو اعتبارها حالة تشابه أسماء طبيعية).
4. **تجربة التجهيل الصارم لبيانات المحلل:**
   - من شريط التبديل السريع، اختر **«محلل بيانات وتخطيط»**.
   - لاحظ فوراً كيف تتحول الأسماء والأرقام الوطنية إلى معرفات مستعارة مشفرة (`ANON-YE-...`) لحماية كرامة وخصوصية المستفيدين.
